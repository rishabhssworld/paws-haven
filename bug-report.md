# Saturday Shift Board Bug Report

| #   | What I saw                                                                         | Where I found it                       | Cause                                                                                                        | Fix                                                                                  |
| --- | ---------------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 1   | The Console showed `Cannot read properties of null (reading 'addEventListener')`.  | `shift-board.html`, script tag         | The error means the script couldn't find the form. Running the script before the form exists can cause this. | Verified that the script tag has `defer` and that `#shift-form` matches the form ID. |
| 2   | I found that the list selector was missing an `i`.                                 | `shift-board.js`, `shiftList` selector | The script looked for `#shift-lst`, but the HTML used `id="shift-list"`.                                     | Changed the selector to `#shift-list`.                                               |
| 3   | I found that the submit handler didn't stop the browser's default form submission. | `shift-board.js`, submit handler       | Submitting the form could reload the page.                                                                   | Added `event.preventDefault()` at the start of the handler.                          |
| 4   | I found that the empty-name check erased the typed name and skipped the warning.   | `shift-board.js`, empty-name check     | `=` assigned an empty string, which made the condition false.                                                | Changed `=` to `===` so the condition checks whether the name is empty.              |
| 5   | I found that the code tried to increase a counter declared with `const`.           | `shift-board.js`, `signedUp` variable  | JavaScript doesn't allow a `const` variable to be reassigned.                                                | Changed `const signedUp = 0` to `let signedUp = 0`.                                  |
| 6   | I found that the code could display `<b>Ana</b>` as bold text.                     | `shift-board.js`, `addVolunteer()`     | `innerHTML` interpreted the typed name as HTML.                                                              | Replaced `innerHTML` with `textContent` so the name displays as plain text.          |
